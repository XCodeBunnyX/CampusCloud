How it works

  1. Your file is received by the CampusCloud Controller (Flask backend).
  2. The controller validates the filename and file size.
  3. The controller initiates a WebHDFS two-step PUT to the NameNode.
  4. The NameNode returns a DataNode redirect URL (HTTP 307).
  5. File data is streamed directly to the DataNode.
  6. HDFS confirms storage. Metadata is recorded in SQLite.
